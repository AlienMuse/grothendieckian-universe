# Authenticity and Security

The authentic game is the one served from **https://grothendieck.space/** and the build in [`site/`](site) of this
repository. The game is a static site: it loads no code from any third-party origin, sets no cookies, and makes no
request outside its own domain.

Please report privately to **vincent.liu@wisemotif.ai**:

- copies of the game sold, or distributed with modifications;
- accounts, sites or repositories impersonating the author or presenting themselves as official;
- builds with matching names but different contents;
- anything about the game that behaves as it should not (for example, a request to another domain).

Use the subject line "Grothendieckian Universe authenticity report".

If you believe you have found a security problem in the game itself, write to the same address with the subject
"Grothendieckian Universe security report"; please do not open a public issue for it first.
